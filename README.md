# Superstore Sales Analysis

Интерактивный аналитический отчёт по продажам, разработанный в Microsoft Power BI.

## Содержание отчёта

- **Главная** — дерево декомпозиции для исследования структуры продаж.
- **Обзор продаж** — ключевые показатели эффективности и анализ по регионам.
- **Динамика продаж** — анализ продаж во времени, по категориям и клиентам.
- **География и логистика** — географический анализ прибыльности и исследование сроков отправки заказов.

## Интерактивные возможности

- Навигация между страницами с помощью кнопок.
- Фильтрация данных по годам.
- Интерактивное дерево декомпозиции.

## Инструменты

Microsoft Power BI, Power Query, DAX.

## Как открыть отчёт

Скачайте файл `Superstore_Sales_Analysis.pbix` из репозитория и откройте его в Power BI Desktop.
